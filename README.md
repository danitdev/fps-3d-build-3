# 🔫 3D FPS Systems Prototype

A fast-paced 3D FPS prototype focused on movement, weapon systems, and enemy AI.

This project was built to experiment with FPS mechanics inspired by the movement and gameplay style of **Karlson by Dani**, without being a complete game or having a gameplay loop.

## 🎮 Features

### 🏃 Player Movement

* WASD movement
* Sprinting
* Sliding
* Jumping
* Fast-paced FPS movement

### 🔫 Weapon System

* Multiple weapons
* Weapon switching using the mouse wheel
* Shooting system
* Weapon reloading
* Pistol with animation
* Additional weapons currently have no shooting animations

### 🤖 Enemy AI

Enemies use a state-based system with different behaviors, including:

* Idle
* Following the player
* Shooting at the player
* Jumping
* State-based behavior transitions

### ❤️ Pickups

* Health kits for restoring health
* Ammo kits for replenishing ammunition

### 🎮 Input System

The project uses Unity's **New Input System** for handling player controls and gameplay inputs.

## 🎮 Controls

| Input         | Action            |
| ------------- | ----------------- |
| `W A S D`     | Move              |
| `Shift`       | Speed Up / Sprint |
| `Ctrl`        | Slide             |
| `Space`       | Jump              |
| `Mouse Wheel` | Switch Weapons    |
| `Left Click`  | Shoot             |
| `R`           | Reload            |

## 📌 Project Status

🟡 **Prototype**

This project is primarily focused on experimenting with FPS systems and mechanics rather than delivering a complete game.

The main focus was on:

* FPS movement
* Weapon switching, shooting, and reloading
* Enemy state machines
* Player/enemy interactions
* Health and ammo pickups
* Unity's New Input System

## 🎯 Inspiration

The movement and overall fast-paced FPS feel were inspired by **Karlson**, created by Dani.

This project is an independent prototype and is not affiliated with or a recreation of Karlson.
